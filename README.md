# 📦 Stockella – Sistema Inteligente de Inventario
# RAMA DE ANGELA
Stockella es un sistema web diseñado para optimizar la gestión de inventarios en **bodegas y pequeños comercios**, utilizando:

- Lectura de **código de barras**
- Visión por computadora (TensorFlow/Python)
- Notificaciones push (Google FCM)
- Reportes automáticos
- Control de productos, usuarios, movimientos y alertas

---

## 🚀 Tecnologías principales

### **Frontend**
- React + Vite
- TailwindCSS
- Axios

### **Backend**
- Node.js + Express
- PostgreSQL (Sequelize ORM)
- JWT Authentication
- AWS S3 (subida de imágenes)
- FCM (notificaciones)

### **Infraestructura**
- Railway / Render (Backend)
- Vercel (Frontend)
- PostgreSQL Cloud
- AWS S3 
- EC2 para módulo ML (fase final del proyecto)
